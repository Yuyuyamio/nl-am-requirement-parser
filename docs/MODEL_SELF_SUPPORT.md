# 模型本体承托：可选的永久支撑模式（历史 V3）

2026-08-31 后续修改：默认已切换为可拆支撑，见 `DETACHABLE_SUPPORT.md`。本文保留永久承托模式的行为和历史验证记录；以下“默认”描述指此前版本。永久模式需显式指定 `--support-mode permanent`。它的粗承托属于成品，不能拔除。

生成的模型必须在不依赖可拆支撑的检查中通过。耳朵、下巴、手臂、悬臂等没有名称分支：程序读取实际切片缺陷的位置，并检查相邻三角面的过悬范围，在主体或底座内寻找真实锚点，生成永久承托，与源模型做加材合并。外观会出现可见承托。

入口是 `prepare_verified_print`，自动生成任务的 `ProductionServices` 和本地 `scripts/prepare_verified_print.py` 都调用它。默认启用；精密零件可显式禁用改形，不能通过的结果会被拦截。保护区域用打印坐标系中的 `critical_regions` 传入。没有声称能自动识别所有零件的功能或所有模型的解剖方向。

流程：标准坐标导入 → 平底检查/底座 → 真实切片 → 不计可拆支撑的检查 → 最多两轮局部加材 → 检查通过后才运行 Auto Orient → 再切片、再检查 → 文件哈希绑定验收凭据 → 发布。自动摆放不得翻倒原有向上方向；失败的中间切片和旧缓存不能冒充最终结果，旧支撑重试不能重置两轮预算。

原有严格检查默认行为和阈值保留。生产入口额外使用 `credit_removable_support=False`。短桥仍必须符合原有两端锚定规则。模型本体修复不会使用全局体素重建、减材或修改源文件。原 GPR 的 5% 保真预算没有放宽；可见承托属于另行报告的结构改形，单轮加材上限仍为20%。

本次验证使用 X1 Carbon / 0.4 mm 喷嘴 / PLA，关闭可拆支撑，100% 填充，0.12 mm 层高，取消首层收缩。具体机器、材料和设置改变后必须重新验证。没有进行实体试打。

## 复现

在项目根目录运行：

```powershell
.venv\Scripts\python.exe scripts/prepare_verified_print.py 输入模型.glb 新目录/结果.gcode.3mf --height-mm 30 --support-mode permanent
```

STL 输入使用 +Z 向上，GLB 使用标准 +Y 向上。未指定高度时保持输入毫米尺寸。可传入 `--machine`、`--process`、`--filament` 固定本地配置。输出路径必须不存在。`--no-allow-structural-changes` 禁止改形。

```powershell
.venv\Scripts\python.exe scripts/run_printable_repair_regressions.py
```

这是一套通用、可复现并且会拒绝无法安全处理模型的生产规则，不是“任意模型一定修好”的保证。长期需求中的上游重新生成仍应遵守现有次数限制，不能通过放宽检查来替代重设计。
