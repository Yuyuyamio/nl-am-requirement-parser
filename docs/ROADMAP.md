# Roadmap

## Phase 0：项目骨架

- 建立目录结构
- 读取中文文本
- 输出 JSON
- 添加自动测试
- 发布到 GitHub

## Phase 1：正式需求 Schema

- 产品与功能
- 几何与接口
- 材料
- 载荷与边界条件
- 性能目标
- 增材制造约束
- 缺失信息与冲突

## Phase 2：单位和术语归一化

- N、kN
- mm、cm、m
- MPa、GPa
- 中文工程术语

## Phase 3：接入大语言模型

- 结构化输出
- 禁止编造工程参数
- 保存原始证据
- 验证模型输出

## Phase 4：制造知识库

- 材料数据
- 设备能力
- 最小壁厚
- 悬垂角
- 支撑策略

## Phase 5：对接 CAD 生成模块

- 将确认后的需求文件传给第二模块
- 保持语义解析与模型生成解耦
