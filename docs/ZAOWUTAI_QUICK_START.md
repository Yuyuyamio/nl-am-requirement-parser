# 造物台正式使用入口

本机网站：<http://127.0.0.1:8765/>。网页右上角的“使用流程”提供完整中文说明。

## 每次使用

1. 关闭 Bambu Studio 窗口，保持电脑运行。当前主要验证配置为 X1 Carbon / 0.4 mm 喷嘴 / PLA。
2. 打开造物台，保持“自动打印”关闭，描述物品、尺寸、姿态和材料。
3. 等待生成、几何修复、可拆支撑、真实 Auto Orient、重新切片及最终复检。
4. “最终成品”默认叠加显示成品本体和真实可拆支撑。先下载 **01 含真实支撑切片 G-code 3MF**；02 是可编辑工程，需要重新切片后才显示支撑；03 STL 只含成品本体。没有测试小样混入成品。
5. 在 Bambu Studio 查看模型外观、平底、首层与支撑。改变尺寸、朝向或参数后，必须重新切片和验收。
6. 如需网站开打，先验证打印机连接，再点“确认并开始打印”。首次试打观察首层；冷却后小心拆支撑。

左侧最近任务支持置顶、取消置顶和删除。置顶状态会跨网站重启保留；删除前会确认，运行任务会被拒绝，已删除的任务资料先保存在 `outputs/automatic_jobs/.deleted_jobs/`。

Bambu Studio 成功生成切片文件后即直接放行，不再执行自制的支撑接触、层间可达性、平底或拆卸性验收。开启自动打印时，流程随后直接上传并发送一次开打指令；只有切片命令、文件传输或打印机启动动作本身失败才会停止。

## 重启网站

在项目目录的 PowerShell 运行：

```powershell
.\scripts\run_print_frontend.ps1
```

该脚本使用项目现有 Python 环境，在本机 8765 端口启动并打开网站。窗口关闭会结束服务；只关闭浏览器不会停止后台任务。

需要已配置的 `OPENROUTER_API_KEY`（需求理解）和原有 WSL 本地图像 / TripoSG 模型环境。密钥不要填写在需求框或公开文件里。这里的“本地网站”不代表需求理解完全离线；本轮验证没有重新调用付费需求理解或模型生成。

## 数据与验证边界

- 正式任务记录在 `outputs/automatic_jobs/<任务编号>/`，保留事件与验收记录。
- 默认使用 `support_mode=detachable`：切片可拆支撑与成品本体分开，禁止自动退回粗大永久支柱。
- 网页提供 Bambu 生成的 G-code 3MF、可编辑工程和本体 STL。下载时仅检查文件仍属于当前任务且内容未被改动；这些完整性检查不评价模型或支撑是否可打印，也不参与打印放行。
- 暂停和停止在安全步骤边界生效。已发送的打印指令不会自动重放；网页不是实体急停。
- 软件通过不等于已经实物打印成功，也不证明实际拆支撑的力度。材料、喷嘴、冷却和设备状态都需要首件确认。

用户此前确认外形的小鼠交付包仍单独保存在 `outputs/printable_delivery/20260831_mouse_main_only/`，它不是新任务的模板，也不会自动被替换为其他任务的成品。
