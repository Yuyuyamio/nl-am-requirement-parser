从描述到成品文件

默认先生成模型并交给 Bambu Studio 切片，不连接、上传或启动打印机。勾选“自动打印”后，Bambu 切片成功就会直接上传并开打，提交时会再次提醒。

开始前

  • 保持电脑运行。需求理解使用已配置的 OpenRouter；模型生成使用本机 WSL 环境里的图像生成和 TripoSG，需要已有模型与显卡环境。
  • 关闭 Bambu Studio 的窗口，让后台独占切片程序。完成后再打开成品；网页暂停不是强制终止正在执行的模型生成或切片。
  • 目前主要验证的组合是 X1 Carbon、0.4 mm 喷嘴、PLA。其他设备、材料、喷嘴或缩放后的文件，需要重新配置和检查，不能直接套用现成刀路。

1. 写清物品、尺寸和姿态

例如：“一个 30 毫米高、坐姿的卡通小鼠摆件，屁股和脚朝下，保留大耳朵，底面平整，PLA。”语音转写完成后可以编辑，再提交。避免只写“做得好看”“大一点”等无法确定尺寸的描述。

左侧最近任务中的“置顶”会把常用对话固定到列表顶部，重启网站后仍然保留。“删除”会先确认，运行中的任务不能删除；已结束任务会从列表移除并转存到本地回收目录，以便误删后恢复。

2. 等待 Bambu Studio 完成切片

理解需求 → 生成并整理模型尺寸 → Bambu Auto Orient → Bambu 自动树状支撑 → Bambu 切片 → 下载或直接打印。

Bambu Studio 成功生成目标切片文件后立即放行。系统不再检查平底、悬空面积、刀路可达性、支撑接触或拆卸间隙，也不会因为这些自制判断重新生成模型。

旧任务若曾被这些检查拦下，可以复用已有模型按新版重新切片。软件调用失败、切片文件没有生成、上传失败或打印机拒绝启动仍会如实报错。

3. 下载正确文件

  • 01_含真实支撑切片_先打开这个.gcode.3mf：默认预览入口。在 Bambu Studio 的“预览”中查看已经生成的层、底部与可拆支撑。
  • 02_可编辑工程_切片后显示支撑.3mf：需要调整参数时使用。它保存模型与支撑设置，但必须重新切片后才会显示支撑，不能把“准备”页面中只见模型本体误当成没有支撑。
  • 03_仅成品本体_不含支撑.stl：需要另行编辑时使用；它本来就不包含可拆支撑。

网页默认把本体 STL 与 Bambu G-code 3MF 中的真实支撑刀路叠加显示；蓝色是成品本体，绿色是可拆支撑，橙色是接触界面。可以关闭支撑或切换正面、侧面和立体视角。预览与下载只核对文件属于当前任务且未被替换；这不是可打印性验收。改变尺寸、朝向或切片参数后，请重新切片。

4. 由你决定开打

默认只生成文件时，可以在成品页手动开打。开启“自动打印”时不会停下来等待人工查看：Bambu 切片成功后直接上传并发送启动指令。访问码只保存在本次服务进程内，不会写入任务记录。

启动打印后不要重复发送；软件无法确定是否已开打时，会要求人工核对。网页“停止任务”只停止后续软件步骤，不是打印机急停。

目前验证到哪里

系统完全采用 Bambu Studio 的自动定向、树状支撑和切片结果，不再额外评判平底、悬空、刀路可达性或支撑分离间隙。第一次打印仍请观察首层，冷却后小心拆除支撑。

网站在本机运行，地址为 http://127.0.0.1:8765/。关闭浏览器不会自动停止后台任务；先在网页停止不再需要的任务。重启服务后，已完成记录保留，未完成任务需要从安全步骤重试。
