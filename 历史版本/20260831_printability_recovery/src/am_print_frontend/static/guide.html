从描述到成品文件

默认先生成和检查文件，不连接、上传或启动打印机。勾选“自动打印”会改变这个行为，提交时会再次提醒。

开始前

  • 保持电脑运行。需求理解使用已配置的 OpenRouter；模型生成使用本机 WSL 环境里的图像生成和 TripoSG，需要已有模型与显卡环境。
  • 关闭 Bambu Studio 的窗口，让后台独占切片程序。完成后再打开成品；网页暂停不是强制终止正在执行的模型生成或切片。
  • 目前主要验证的组合是 X1 Carbon、0.4 mm 喷嘴、PLA。其他设备、材料、喷嘴或缩放后的文件，需要重新配置和检查，不能直接套用现成刀路。

1. 写清物品、尺寸和姿态

例如：“一个 30 毫米高、坐姿的卡通小鼠摆件，屁股和脚朝下，保留大耳朵，底面平整，PLA。”语音转写完成后可以编辑，再提交。避免只写“做得好看”“大一点”等无法确定尺寸的描述。

2. 等待完整检查

理解需求 → 生成模型 → 检查和修复网格 → 统一尺寸与坐标 → 修复平底、生成可拆支撑 → 实际切片检查 → Auto Orient → 再切片复检 → 成品文件。

耳朵等悬垂部位由切片支撑承托，支撑与模型留有分离间隙。局部几何修复受改动量和高度限制，不会用粗大的永久柱子兜底。摆正后若改变了应有的直立姿态、底面不合格或仍有危险悬空，会拒绝验收。

修复失败最多触发一次重新生成；仍不合格则停止，不会上传或开打。请根据错误修改需求后新建任务。旧任务缺少新版验收记录时，不会被当作合格成品下载。

3. 下载正确文件

  • 01_成品模型_打开这个.3mf：在 Bambu Studio 打开，查看真实成品和已验证的放置姿态。
  • 02_最终切片_查看支撑.gcode.3mf：查看已经生成的刀路、底层与可拆支撑。它才包含实际打印支撑。
  • 03_成品几何_不含支撑.stl：需要另行编辑或重新切片时使用；只包含成品本体。

网页的可旋转预览直接读取最终 STL，不使用上游参考图，也不显示测试小样。下载时重新校验文件内容，文件被更改或丢失会被拒绝。不要在下载后改变尺寸、朝向或切片参数，却继续沿用旧验收结论。

4. 由你决定开打

先检查模型外形、平底、首层和支撑。需要网站开打时，点击“连接打印机”，输入设备信息和访问码并验证；返回成品，点击“确认并开始打印”。准备好正确材料、喷嘴和干净空平台后再确认。访问码只保存在本次服务进程内，不会写入任务记录。

启动打印后不要重复发送；软件无法确定是否已开打时，会要求人工核对。网页“停止任务”只停止后续软件步骤，不是打印机急停。

目前验证到哪里

软件检查涵盖平底、姿态、最终刀路、悬空和支撑分离间隙。它不能代替实物试打，尤其不能保证不同材料的支撑一定轻松拆下。第一次打印请观察首层，冷却后小心拆支撑；任何失败都不要强行开打。
